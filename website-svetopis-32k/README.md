# СВЕТОПИСЬ — Qwen3.8-Flash-Next · 32K local generation test

Эксперимент от 25 ноября 2026 года: создание красивой фотогалереи локальной моделью Qwen3.8-Flash-Next UD-IQ4_XS в Strata. Два отдельных окна по 32K токенов, одна видеокарта RX 7800 XT. Дизайн получился удачным; код опубликован с исходными дефектами, без ручного улучшения.

## Исходный промпт

Оригинальная формулировка со всеми опечатками:

```text
напиши тестовый красивый сатй вотогалереи
```

Никакого подробного ТЗ на дизайн. Модель сама выбрала тему аналоговой фотографии, структуру сайта, визуальный стиль и интерактивность. Дизайн — ретро-архив с контактным листом, анимированными фотографиями, EXIF, masonry-галереей, фильтрами, сериями, открытками, авторами, выставками, дневником, отпечатками и lightbox.

## Посмотреть сайт

Откройте `index.html` в браузере. Сборка и установка зависимостей не нужны. Для загрузки фотографий Picsum и Google Fonts нужен интернет. Изображения и сведения об архиве демонстрационные, а не подтверждённый исторический каталог. Форма не отправляет данные на сервер.

### Фактически наблюдавшиеся ресурсы

- 3706 экспертов в VRAM (8.3 GB по монитору Strata).
- VRAM: 15.3 / 16 GB; RAM: 56.7–57.8 / 63 GB по монитору.
- GPU edge: около 39–40 °C во время генерации; hotspot 50 °C в одном снимке SysMon.
- PCIe Gen4 x16. Генерация на CPU + GPU с использованием RAM и файлового уровня; вся модель не помещается в VRAM.

## Ход эксперимента

1. Qwen получила короткий промпт и сгенерировала 83 246 байт HTML/CSS/JS. Контекст закончился посередине обработчика формы.
2. Исходник сохранён без изменений. ChatGPT подготовил внешнюю контрольную точку `SVETOPIS-STATE.md`: состояние, план, нужные фрагменты исходника и точное место обрыва.
3. В новом чате Strata модель получила контрольную точку и промпт продолжения (ниже). Она дописала отсутствующий хвост, не повторяя старый код.
4. Два результата объединены в `index.html`. Исходник первого чата остался побайтно неизменным, второй фрагмент добавлен в конец. Синтаксис полного JS проверен `node --check`. Полная функциональная верификация не заявляется.

Это ручной эксперимент с файловой памятью, а не автономная реализация RAG или автоматической ротации. Генерацию сайта выполнила локальная Qwen; подготовка контрольной точки и объединение файлов выполнялись с помощью ChatGPT.

## Известные ограничения и дефекты

- В `onScroll` используется локальная переменная `scrollY` из lightbox вместо актуального `window.scrollY`. Это влияет на индикатор прокрутки, компактную шапку и подсветку навигации. Дефект оставлен намеренно.
- Форма — локальная демонстрация без реальной отправки.
- Фотографии Picsum не обязательно соответствуют описаниям. Имена, контакты и сведения на странице — демонстрационный контент, не использовать как реальные реквизиты.
- Первая генерация оборвалась на лимите контекста, не завершив исходник. Сохранена как артефакт эксперимента.
